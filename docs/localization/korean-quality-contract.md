# MİZAN GLOBAL 한국어 최종 품질 계약

한국어(`ko`, `ko-KR`)는 다음 조건을 모두 만족할 때만 완료로 간주한다.

- 안정된 제품 소스와 정확히 동일한 791/791 시스템 키를 사용하며 누락·중복·빈 값이 없다.
- 대한민국 금융·결제 앱에서 자연스럽게 쓰이는 한국어를 사용한다.
- 사용자 입력 이름, 메모, 은행명, 식별자, 사용자 지정 메시지는 번역하지 않는다.
- 보고서, 차트, PDF, CSV/백업, 알림, 검증, 설정, 오류/빈 상태도 같은 한국어 격리 규칙을 적용한다.
- 일본어 히라가나/가타카나 시스템 문구와 중국어 시스템 문장이 한국어 화면에 섞이면 실패다.
- KRW는 대한민국 표시 관습을 따르며 원화는 소수점 없이 `₩1,234,567`로 표시한다. 다른 기록별 통화는 서로 합산·환산하지 않는다.
- 날짜는 그레고리력 기준 `2026년 8월 7일`, 월 표기는 `2026년 8월`을 사용한다.
- 29개 언어, 161개 국가, 154개 통화에 대한 오프라인 한국어 표시명/검색명을 제공한다.
- 320×568/1.4×, 412×915/2.0× 반응형 검사와 전체 기존 언어 회귀, 동일 SHA의 universal/ARM64/ARMv7/x86_64 APK 검증을 통과한다.
