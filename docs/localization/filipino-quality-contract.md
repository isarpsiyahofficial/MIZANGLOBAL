# Kontrata sa Panghuling Kalidad ng Filipino

- Wika: Filipino (`fil`, `fil-PH`), LTR. Hindi ito idaragdag sa runtime supported-language list hangga't hindi kumpleto ang buong 791/791 na system copy.
- Lahat ng menu, form, validation, error/empty state, setting, notification, reminder, report, chart, PDF, CSV at backup text ay kailangang natural na Filipino at walang Turkish/English/Indonesian/Malay fallback.
- Pangunahing terminolohiya: utang, pagbabayad, gastusin, kita, bayarin, subscription, upa, hulugan, ulat, paalala, notification, backup at talaan.
- Ang pangalan, tala, paglalarawan, IBAN, ISO code at ibang user-authored data ay hindi isasalin o babaguhin.
- PHP formatting, Gregorian Philippine dates, 29/161/154 offline catalog names at currency-search aliases ay kailangang hiwalay at kumpleto.
- Hindi pagsasamahin ang magkakaibang currency sa report, chart, PDF, CSV o summary at walang awtomatikong FX conversion.
- Bago maging final: 791-key parity, native-copy audit, dynamic grammar, reports/PDF/notifications, storage/CSV/backup, responsive screens, all-language regression, visual baseline at apat na release APK sa iisang SHA kapag available ang runner.
